🔢 Number JS Dashboard

Guia rápido e visual

🟢 Básico

  • typeof → typeof 10
  • Number() → Number("10")
  • parseInt() → parseInt("10.9")
  • parseFloat() → parseFloat("10.9")

🟡 Métodos

  • toFixed() → 10.456.toFixed(2)
  • toPrecision() → 123.456.toPrecision(4)
  • toString() → (10).toString()
  • valueOf() → new Number(10)

🟠 Validação

  • isNaN() → Number.isNaN(NaN)
  • isInteger() → Number.isInteger(10)
  • isFinite() → Number.isFinite(100)
  • isSafeInteger() → Number.isSafeInteger(10)

🔵 Math

  • round() → Math.round(4.6)
  • floor() → Math.floor(4.9)
  • ceil() → Math.ceil(4.1)
  • random() → Math.random()
  • max() → Math.max(1,2,3)
  • min() → Math.min(1,2,3)

🔴 Avançado

  • Number.MAX_VALUE → Maior número
  • Number.MIN_VALUE → Menor positivo
  • Number.MAX_SAFE_INTEGER → Limite seguro
  • Number.MIN_SAFE_INTEGER → Limite seguro
  • BigInt → 123n
  • 0.1 + 0.2 → Erro de precisão
